# corexy-plotter
Fallen

Custom postcards with CoreXY pen plotter, ESP32 based, interactive with iPad interface (hopefully)

I decided to make this project as I have always had a deep interest in art and design. Engineering, as an intersection between design and science, allows me to work on mechanically curious and creative projects.

For Maker Faire 2026 @ Shenzhen, I thought it would be a memorable project to make souvenir postcards drawn with my project, a pen plotter. Compared to other mechanisms, CoreXY is known for its accuracy and speed - as well as complexity. I felt like this plotter would challenge me and allow me to learn many new skills such as firmware implementation and 3D design.
